# Account Deletion

This document explains the data deletion process for Voxlist Ai.

## In-app method

Use the Delete account option in the Settings screen when you are signed in.

## Deletion request details

When a deletion request is confirmed, the App will:

- remove the authenticated user from Supabase Auth
- delete stored tasks linked to that account
- remove cloud data associated with the user where applicable
- sign the user out of the App

## Contact method

If you cannot use the in-app flow, contact:

support@voxlistai.app

Include your email address and a note that you want to delete your Voxlist Ai account and all associated data.

## Timing

Most account deletions are processed promptly after verification. Some cloud or backup copies may remain for a limited period for security, backup, or operational reasons.
